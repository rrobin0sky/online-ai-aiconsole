FAQ

常见问题与解答

AI 助手需要绑定特定的模型服务商吗？

不强制。AIConsole 内置了标准 OpenAI 协议客户端，你可以无缝接入 DeepSeek、OpenAI、Claude、Gemini，甚至局域网运行的本地 Ollama。API Key 完全存储在你本地的 macOS Keychain 中，绝不上云。

遇到 macOS 提示“无法打开，因为无法验证开发者”怎么办？

由于本应用采用本地 Ad-hoc 代码签名，若首次打开出现提示，请在「系统设置」➔「隐私与安全性」中找到 AIConsole 并点击「仍要打开」，或在终端执行 xattr -cr /Applications/AIConsole.app 即可。

是否支持 Intel 架构的 Mac 设备？

当前编译产物主要针对 Apple Silicon (M1/M2/M3/M4) 系列芯片深度优化。若需要在 Intel 芯片设备运行，可通过源码执行 swift build -c release 编译属于当前机器的二进制。
