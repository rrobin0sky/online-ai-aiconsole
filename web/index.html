首次打开提示“无法打开 / 无法验证开发者”？ 3 秒解决

因该项目为 GitHub 开源应用，macOS Gatekeeper 安全机制会自动对网络下载的未付费证书应用添加临时隔离。请选择以下任意一种方式立即解除：

极速方案：在 Mac 终端执行一键解除命令
xattr -cr /Applications/AIConsole.app
无需终端法：打开 Mac「系统设置」➔「隐私与安全性」➔ 找到 AIConsole 并点击「仍要打开」即可。

FAQ

解答你的疑虑

为什么下载后首次打开提示“无法打开 / 无法验证开发者”？

这是 macOS 系统 Gatekeeper 对网络直接下载且未购买年费企业签名证书软件的标准隔离机制。只需在终端运行 xattr -cr /Applications/AIConsole.app，或者在 Mac「系统设置 ➔ 隐私与安全性」中点击「仍要打开」，之后即可永久正常使用。

我的远程服务器密码和 API Key 存在哪里？

所有密码、私钥和 AI API Key 均直接加密保存在你 Mac 本地的系统钥匙串（macOS Keychain）中，不经过任何第三方服务器中转，具有完全的本地离线隐私性。

支持哪些大语言模型服务？

只要支持 OpenAI 兼容接口的模型均可原生接入，包括 DeepSeek、OpenAI GPT-4o、Anthropic Claude、Google Gemini，以及内网本地运行的 Ollama 离线模型。
